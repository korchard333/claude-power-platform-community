# Dataverse — Naming Conventions

## Naming Conventions

| Object | Convention | Example |
|---|---|---|
| Publisher prefix | 2-5 chars, lowercase | `contoso_` |
| Table display name | Title Case, singular | `Project Task` |
| Table schema name | lowercase with prefix | `contoso_projecttask` |
| Column display name | Title Case | `Due Date` |
| Column schema name | lowercase with prefix | `contoso_duedate` |
| Choice option labels | Title Case | `In Progress` |
| Global option set | Prefixed, descriptive | `contoso_projectstatus` |
