# Responsive Design

## Breakpoints
```css
/* Mobile-first approach */
sm:  640px   /* Large phones */
md:  768px   /* Tablets */
lg:  1024px  /* Small laptops */
xl:  1280px  /* Desktops */
2xl: 1536px  /* Large desktops */
```

## Responsive Patterns for Enterprise Apps
| Pattern | Mobile | Tablet | Desktop |
|---|---|---|---|
| Navigation | Bottom tab bar or hamburger | Collapsible sidebar | Persistent sidebar |
| Data tables | Card list (stacked) | Horizontal scroll table | Full table |
| Forms | Single column, full width | Single column, centered | Single column, max-width |
| Dashboards | Stacked cards | 2-column grid | 3-4 column grid |
| Actions | Full-width buttons | Inline buttons | Inline buttons |

**Note:** Code Apps currently do NOT support Power Apps mobile. Responsive design is for browser viewport resizing and tablet browsers, not the Power Apps mobile app.
